# Nouns: Plural Forms (A1)

In German, there is no single rule for making nouns plural. You must learn the plural form together with the noun from the beginning.

## Why this matters
- Affects articles (die becomes die for ALL plurals)
- Changes the noun ending
- Essential for speaking about multiple things
- Appears in all cases (Nominative, Accusative, Dative plural)

## The Good News
- **All plural nouns use "die"** as the article (regardless of original gender)
  - der Tisch → die Tische
  - die Lampe → die Lampen
  - das Buch → die Bücher

## The 5 Main Plural Patterns

### Pattern 1: Add **-e** (masculine & neuter, many one-syllable words)
| Singular | Plural | Example |
| :--- | :--- | :--- |
| der Tisch (table) | die Tische | Die Tische sind neu. |
| der Tag (day) | die Tage | Sieben Tage eine Woche. |
| das Heft (notebook) | die Hefte | Meine Hefte sind voll. |

**With umlaut** (a → ä, o → ö, u → ü) for some:
| Singular | Plural | Example |
| :--- | :--- | :--- |
| der Ball (ball) | die Bälle | Die Kinder spielen mit Bällen. |
| der Sohn (son) | die Söhne | Ihre Söhne sind groß. |

### Pattern 2: Add **-n/-en** (mostly feminine)
| Singular | Plural | Example |
| :--- | :--- | :--- |
| die Frau (woman) | die Frauen | Die Frauen arbeiten. |
| die Lampe (lamp) | die Lampen | Die Lampen leuchten. |
| die Tasse (cup) | die Tassen | Fünf Tassen Kaffee. |
| die Studentin (female student) | die Studentinnen | Die Studentinnen lernen. |

### Pattern 3: Add **-er** + umlaut (many neuter, some masculine)
| Singular | Plural | Example |
| :--- | :--- | :--- |
| das Kind (child) | die Kinder | Die Kinder spielen. |
| das Buch (book) | die Bücher | Die Bücher sind teuer. |
| der Mann (man) | die Männer | Die Männer kommen. |

### Pattern 4: Add **-s** (foreign words, family names, abbreviations)
| Singular | Plural | Example |
| :--- | :--- | :--- |
| das Auto (car) | die Autos | Viele Autos in der Stadt. |
| der Laptop | die Laptops | Meine Laptops sind neu. |
| das Hobby | die Hobbys | Meine Hobbys sind Sport. |

### Pattern 5: No change (or only umlaut)
| Singular | Plural | Example |
| :--- | :--- | :--- |
| der Löffel (spoon) | die Löffel | Die Löffel sind sauber. |
| der Apfel (apple) | die Äpfel | Ich kaufe Äpfel. |
| das Mädchen (girl) | die Mädchen | Die Mädchen singen. |
| der Vater (father) | die Väter | Meine Väter? (unusual) |

## Quick Reference: Pattern by Gender

| Gender | Most Common Pattern | Example |
| :--- | :--- | :--- |
| **masculine** | -e (often with umlaut) | der Tisch → die Tische |
| **feminine** | -n/-en | die Lampe → die Lampen |
| **neuter** | -er (often with umlaut) | das Kind → die Kinder |
| **all genders** | -s (foreign words) | das Auto → die Autos |

## Special Cases

### Words that only exist in plural
- die Leute (people)
- die Eltern (parents)
- die Ferien (vacation/holidays)

### Same word, different meaning in plural
- die Bank → die Bänke (benches) vs. die Banken (banks - financial)
