# Verbs: Modal Verbs (können, mögen, wollen) - A1

Modal verbs are special verbs that modify the meaning of another verb. They express **ability**, **desire**, **preference**, or **intention**. They are extremely common in daily conversation.

## Why this matters
- You use them constantly: "I can," "I want," "I like"
- They change the sentence structure (modal in position 2, main verb at the end)
- They have irregular conjugation (but the pattern is consistent)
- Essential for sounding natural and expressing yourself properly

## The Golden Rule: Modal + Infinitive at the End

When you use a modal verb in a sentence, the **modal is conjugated** and stays in position 2, while the **main verb goes to the end** in its infinitive form .

| Structure | Position 1 | Position 2 (Modal) | ... | End (Main Verb) |
| :--- | :--- | :--- | :--- | :--- |
| | Ich | **kann** | gut Deutsch | **sprechen**. |
| | Du | **willst** | ins Kino | **gehen**. |
| | Er | **mag** | Schokolade | **essen**. |

**Important:** The main verb stays in infinitive form (ends in -en) and goes to the very end!

## The Three Core Modal Verbs for A1

### 1. können (can / to be able to) – Expressing Ability

| Person | Conjugation | Example | Translation |
| :--- | :--- | :--- | :--- |
| **ich** | **kann** | Ich kann Deutsch sprechen. | I can speak German. |
| **du** | **kannst** | Kannst du mir helfen? | Can you help me? |
| **er/sie/es** | **kann** | Er kann gut kochen. | He can cook well. |
| **wir** | **können** | Wir können heute kommen. | We can come today. |
| **ihr** | **könnt** | Ihr könnt hier warten. | You guys can wait here. |
| **sie/Sie** | **können** | Sie können mich anrufen. | They/You can call me. |

**Uses of können:**
| Use | Example | Translation |
| :--- | :--- | :--- |
| **Ability/Skill** | Ich kann Klavier spielen. | I can play piano. |
| **Possibility** | Das kann sein. | That could be. |
| **Permission** | Kann ich bitte gehen? | Can I please go? |
| **Knowledge** | Kannst du Englisch? | Do you know English? |

---

### 2. wollen (to want) – Expressing Intention/Desire

| Person | Conjugation | Example | Translation |
| :--- | :--- | :--- | :--- |
| **ich** | **will** | Ich will Deutsch lernen. | I want to learn German. |
| **du** | **willst** | Was willst du essen? | What do you want to eat? |
| **er/sie/es** | **will** | Sie will nach Berlin fahren. | She wants to go to Berlin. |
| **wir** | **wollen** | Wir wollen ein Haus kaufen. | We want to buy a house. |
| **ihr** | **wollt** | Wollt ihr mitkommen? | Do you guys want to come along? |
| **sie/Sie** | **wollen** | Sie wollen uns besuchen. | They/You want to visit us. |

**Uses of wollen:**
| Use | Example | Translation |
| :--- | :--- | :--- |
| **Strong intention** | Ich will Arzt werden. | I want to become a doctor. |
| **Plans** | Wir wollen am Wochenende verreisen. | We want to travel this weekend. |
| **Requests** | Willst du bitte leise sein? | Do you want to please be quiet? |

**Note:** *wollen* expresses a stronger intention than English "want to." For polite requests, use *möchten* (see below).

---

### 3. mögen (to like) – Expressing Preference

| Person | Conjugation | Example | Translation |
| :--- | :--- | :--- | :--- |
| **ich** | **mag** | Ich mag Schokolade. | I like chocolate. |
| **du** | **magst** | Magst du Katzen? | Do you like cats? |
| **er/sie/es** | **mag** | Er mag Fußball. | He likes soccer. |
| **wir** | **mögen** | Wir mögen italienisches Essen. | We like Italian food. |
| **ihr** | **mögt** | Mögt ihr Musik? | Do you guys like music? |
| **sie/Sie** | **mögen** | Sie mögen Filme. | They/You like movies. |

**Important Distinction:**
- **mögen** + noun = to like something/someone
- **mögen** + verb = to like doing something (but less common – usually *gern* is used instead)

| Structure | Example | Translation |
| :--- | :--- | :--- |
| **mögen + noun** | Ich mag Pizza. | I like pizza. |
| **gern + regular verb** | Ich esse **gern** Pizza. | I like eating pizza. |

**Compare:**
- Ich **mag** Schokolade. (I like chocolate – noun)
- Ich **esse gern** Schokolade. (I like eating chocolate – verb)
- Ich **mag** Schokolade **essen**. (possible but less common – I like to eat chocolate)

## Bonus: möchten (would like) – The Polite Form

Technically, *möchten* is the subjunctive form of *mögen*, but at A1 level, it's taught as a separate modal verb for **polite requests and wishes** .

| Person | Conjugation | Example | Translation |
| :--- | :--- | :--- | :--- |
| **ich** | **möchte** | Ich möchte einen Kaffee. | I would like a coffee. |
| **du** | **möchtest** | Möchtest du etwas essen? | Would you like something to eat? |
| **er/sie/es** | **möchte** | Er möchte nach Hause gehen. | He would like to go home. |
| **wir** | **möchten** | Wir möchten zahlen. | We would like to pay. |
| **ihr** | **möchtet** | Möchtet ihr Tee oder Kaffee? | Would you guys like tea or coffee? |
| **sie/Sie** | **möchten** | Sie möchten ein Zimmer reservieren. | They/You would like to reserve a room. |

**Key Difference:**
- **wollen** = want (strong, direct)
- **möchten** = would like (polite, softer)

| Compare | | |
| :--- | :--- | :--- |
| Ich **will** einen Kaffee. | I want a coffee. | (direct, maybe rude) |
| Ich **möchte** einen Kaffee. | I would like a coffee. | (polite, appropriate) |

## Sentence Structure: The "Frame" (Satzklammer)

Modal verbs create a **frame** in the sentence. The conjugated modal is in position 2, and the infinitive goes to the very end .

| Subject | Modal (pos 2) | Middle Field | Infinitive (end) |
| :--- | :--- | :--- | :--- |
| Ich | **kann** | gut Deutsch | **sprechen**. |
| Du | **willst** | ins Kino | **gehen**. |
| Wir | **möchten** | morgen um 8 Uhr | **kommen**. |
| Er | **mag** | keine Schokolade | **essen**. |

### Questions:

**Yes/No Questions** (Modal in position 1):

| Modal | Subject | Middle Field | Infinitive (end) |
| :--- | :--- | :--- | :--- |
| **Kannst** | du | mir | **helfen**? |
| **Willst** | du | nach Berlin | **fahren**? |
| **Möchtet** | ihr | Tee | **trinken**? |

**W-Questions** (Question word in position 1, modal in position 2):

| W-Word | Modal | Subject | Middle Field | Infinitive (end) |
| :--- | :--- | :--- | :--- | :--- |
| Was | **willst** | du | heute | **essen**? |
| Wann | **kannst** | du | mich | **anrufen**? |
| Wo | **möchtet** | ihr | | **wohnen**? |

## Common Mistakes to Avoid

### Mistake 1: Conjugating the main verb ❌
| Wrong | Correct |
| :--- | :--- |
| Ich kann Deutsch **spreche**. | Ich kann Deutsch **sprechen**. |
| Du willst **kommst**? | Du willst **kommen**? |

### Mistake 2: Putting the main verb in position 2 ❌
| Wrong | Correct |
| :--- | :--- |
| Ich **sprechen** kann Deutsch. | Ich **kann** Deutsch **sprechen**. |

### Mistake 3: Using wollen for polite requests ❌
| Too direct | Better (polite) |
| :--- | :--- |
| Ich will einen Kaffee. | Ich **möchte** einen Kaffee. |

### Mistake 4: Confusing mögen and möchten ❌
| Wrong context | Correct |
| :--- | :--- |
| Ich **mag** einen Kaffee bestellen. | Ich **möchte** einen Kaffee bestellen. |
| (I like ordering coffee? No, you mean "would like") | |

## Useful Expressions with Modal Verbs

| Expression | Meaning |
| :--- | :--- |
| **Das kann sein.** | That could be. / Maybe. |
| **Das will ich nicht.** | I don't want that. |
| **Was möchtest du trinken?** | What would you like to drink? |
| **Kannst du mir helfen?** | Can you help me? |
| **Ich mag dich.** | I like you. |
| **Willst du mitkommen?** | Do you want to come along? |
| **Wir möchten zahlen.** | We would like to pay. (in a restaurant) |
| **Das kann ich nicht machen.** | I can't do that. |
