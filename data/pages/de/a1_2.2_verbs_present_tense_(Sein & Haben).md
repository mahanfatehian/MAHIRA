# Verbs: Present Tense (sein & haben) - A1

**sein** (to be) and **haben** (to have) are the two most important verbs in German. They are **irregular**, which means they don't follow the regular conjugation patterns. You will use them constantly in daily conversation.

## Why this matters
- **sein** is used to talk about identity, feelings, location, and characteristics
- **haben** is used to talk about possessions, relationships, and physical states
- Both are used as **auxiliary verbs** to form other tenses (like the perfect tense)
- They appear in countless common expressions
- You cannot form a basic sentence without them

---

## sein (to be) – Fully Irregular

The verb **sein** is completely irregular – it doesn't follow any pattern. You must memorize it.

### Conjugation of sein

| Subject | Conjugation | Example | Translation |
| :--- | :--- | :--- | :--- |
| **ich** | **bin** | Ich bin Thomas. | I am Thomas. |
| **du** | **bist** | Du bist müde. | You are tired. |
| **er/sie/es** | **ist** | Er ist Lehrer. | He is a teacher. |
| | | Sie ist meine Schwester. | She is my sister. |
| | | Es ist kalt. | It is cold. |
| **wir** | **sind** | Wir sind zu Hause. | We are at home. |
| **ihr** | **seid** | Ihr seid nett. | You guys are nice. |
| **sie (they)** | **sind** | Sie sind Studenten. | They are students. |
| **Sie (formal)** | **sind** | Woher kommen Sie? – actually sein: Wo sind Sie? | Where are you? (formal) |

### Common Uses of sein

| Use | Example | Translation |
| :--- | :--- | :--- |
| **Identity/Profession** | Ich bin Maria. | I am Maria. |
| | Er ist Arzt. | He is a doctor. |
| **Location** | Wo ist der Bahnhof? | Where is the train station? |
| | Wir sind in Berlin. | We are in Berlin. |
| **Feelings/States** | Bist du müde? | Are you tired? |
| | Ich bin hungrig. | I am hungry. |
| **Characteristics** | Das Haus ist groß. | The house is big. |
| | Sie ist intelligent. | She is intelligent. |
| **Time/Date** | Es ist 10 Uhr. | It is 10 o'clock. |
| | Heute ist Montag. | Today is Monday. |
| **Origin** | Ich bin aus Deutschland. | I am from Germany. |
| **Weather** | Es ist sonnig. | It is sunny. |

### Important: No Article for Professions!
In German, you don't use an article when saying someone's profession:

| English | German |
| :--- | :--- |
| I am **a** teacher. | Ich bin **–** Lehrer. |
| She is **a** doctor. | Sie ist **–** Ärztin. |

## haben (to have) – Irregular but Patterned

The verb **haben** changes its stem from **hab-** to **ha-** in the du and er/sie/es forms.

### Conjugation of haben

| Subject | Conjugation | Example | Translation |
| :--- | :--- | :--- | :--- |
| **ich** | **habe** | Ich habe eine Frage. | I have a question. |
| **du** | **hast** | Du hast ein Auto. | You have a car. |
| **er/sie/es** | **hat** | Er hat zwei Brüder. | He has two brothers. |
| | | Sie hat Zeit. | She has time. |
| | | Das Kind hat Hunger. | The child is hungry. |
| **wir** | **haben** | Wir haben Geld. | We have money. |
| **ihr** | **habt** | Ihr habt Haustiere. | You guys have pets. |
| **sie (they)** | **haben** | Sie haben ein Haus. | They have a house. |
| **Sie (formal)** | **haben** | Haben Sie einen Termin? | Do you have an appointment? |

### Common Uses of haben

| Use | Example | Translation |
| :--- | :--- | :--- |
| **Possession** | Ich habe ein Handy. | I have a mobile phone. |
| | Hast du Geschwister? | Do you have siblings? |
| **Physical states** | Ich habe Hunger. | I am hungry (I have hunger). |
| | Er hat Durst. | He is thirsty (He has thirst). |
| | Sie hat Fieber. | She has a fever. |
| **Emotional states** | Wir haben Angst. | We are afraid (We have fear). |
| | Ich habe Langeweile. | I am bored (I have boredom). |
| **Time/Appointments** | Hast du heute Zeit? | Do you have time today? |
| | Ich habe einen Termin. | I have an appointment. |
| **Age** | Wie alt hast du? – careful: Age uses **sein**! | |
| | Actually: **Ich bin 25 Jahre alt.** (not haben!) | I am 25 years old. |
| **Measurements** | Das Zimmer hat 20 Quadratmeter. | The room is 20 square meters. |
| **Fixed expressions** | Ich habe Recht. | I am right (I have right). |
| | Du hast Unrecht. | You are wrong (You have wrong). |

### Important: haben + Accusative
**haben** is always followed by the **accusative case**. This affects the articles:

| Gender | Nominative (subject) | Accusative (after haben) |
| :--- | :--- | :--- |
| masculine | **der** Tisch | Ich habe **den** Tisch. |
| | **ein** Tisch | Ich habe **einen** Tisch. |
| feminine | **die** Lampe | Ich habe **die** Lampe. |
| | **eine** Lampe | Ich habe **eine** Lampe. |
| neuter | **das** Buch | Ich habe **das** Buch. |
| | **ein** Buch | Ich habe **ein** Buch. |
| plural | **die** Bücher | Ich habe **die** Bücher. |

**Examples:**
- Ich habe **einen** Bruder. (masculine)
- Ich habe **eine** Schwester. (feminine)
- Ich habe **ein** Auto. (neuter)
- Ich habe **die** Adresse. (feminine, specific)

## Quick Comparison: sein vs. haben

| English | German | Correct Verb |
| :--- | :--- | :--- |
| I am tired. | Ich ___ müde. | **bin** (sein) |
| I am hungry. | Ich ___ Hunger. | **habe** (haben) |
| I have a dog. | Ich ___ einen Hund. | **habe** (haben) |
| I am a student. | Ich ___ Student. | **bin** (sein) |
| It is cold. | Es ___ kalt. | **ist** (sein) |
| It has 3 rooms. | Es ___ 3 Zimmer. | **hat** (haben) |

### Common Mistake Alert!
Many beginners confuse these because English uses "to be" for both:

| Wrong | Correct | Why |
| :--- | :--- | :--- |
| Ich **bin** Hunger. ✗ | Ich **habe** Hunger. ✓ | Hunger is something you HAVE in German |
| Ich **habe** müde. ✗ | Ich **bin** müde. ✓ | Tired is a state of BEING |
| Ich **bin** 25 Jahre alt. ✓ | Ich **habe** 25 Jahre. ✗ | Age uses SEIN in German |

## Important Fixed Expressions

### sein + adjective (describing states)
- Ich bin müde. (I am tired)
- Bist du krank? (Are you sick?)
- Es ist spät. (It is late)
- Wir sind fertig. (We are ready)

### haben + noun (common idioms)
| Expression | Literal | Meaning |
| :--- | :--- | :--- |
| Hunger haben | to have hunger | to be hungry |
| Durst haben | to have thirst | to be thirsty |
| Angst haben | to have fear | to be afraid |
| Zeit haben | to have time | to have time |
| Recht haben | to have right | to be right |
| Glück haben | to have luck | to be lucky |
| Kopfschmerzen haben | to have head pains | to have a headache |
| Fieber haben | to have fever | to have a temperature |
| Langeweile haben | to have boredom | to be bored |
