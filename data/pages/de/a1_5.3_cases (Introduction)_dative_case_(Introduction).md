# Cases: Dative (Indirect Object) - A1

The **dative case** is used for the **indirect object** of a sentence – the person or thing that benefits from the action or receives something .

## Why this matters
- You already know and use dative phrases without realizing it: **"Wie geht es dir?"** (How are you?)
- Many common verbs require the dative (**helfen**, **danken**, **gefallen**)
- Certain prepositions are **always** followed by the dative (aus, bei, mit, nach, von, zu)
- Essential for sounding natural in everyday conversations

## The Golden Rule: The Dative Answers "Wem?" (To Whom?)

To find the indirect object in a sentence, ask **"Wem?"** (to whom/for whom) .

| Question | Answer (Dative) |
| :--- | :--- |
| **Wem** hilfst du? (To whom are you helping?) | Ich helfe **dem Mann**. |
| **Wem** dankt sie? (To whom is she thanking?) | Sie dankt **ihrer Mutter**. |
| **Wem** gehört das Buch? (To whom does the book belong?) | Das gehört **meinem Bruder**. |

## Part 1: Dative Article Changes

In the dative case, **all genders change** – unlike accusative where only masculine changed.

| Gender | Nominative (Subject) | Dative (Indirect Object) |
| :--- | :--- | :--- |
| **masculine** (der) | **der** Mann | **dem** Mann |
| | **ein** Mann | **einem** Mann |
| | **mein** Bruder | **meinem** Bruder |
| **neuter** (das) | **das** Kind | **dem** Kind |
| | **ein** Kind | **einem** Kind |
| | **mein** Buch | **meinem** Buch |
| **feminine** (die) | **die** Frau | **der** Frau |
| | **eine** Frau | **einer** Frau |
| | **meine** Schwester | **meiner** Schwester |
| **plural** (die) | **die** Kinder | **den** Kindern **+ n** |

### Special Plural Rule:
In dative plural, the noun adds an **-n** if it doesn't already have one [citation:5].

| Nominative Plural | Dative Plural |
| :--- | :--- |
| die Kinder | **den** Kinder**n** |
| die Frauen | **den** Frauen (already ends with -n) |
| die Autos | **den** Autos (foreign words usually don't add -n) |

## Part 2: Dative Pronouns

Personal pronouns also change in the dative case :

| Nominative | Dative | English | Example |
| :--- | :--- | :--- | :--- |
| **ich** | **mir** | (to/for) me | **Mir** geht es gut. |
| **du** | **dir** | (to/for) you | Ich helfe **dir**. |
| **er** | **ihm** | (to/for) him | Das gehört **ihm**. |
| **sie** (she) | **ihr** | (to/for) her | Wir danken **ihr**. |
| **es** | **ihm** | (to/for) it | Gib **ihm** das Futter! (dem Hund) |
| **wir** | **uns** | (to/for) us | Kannst du **uns** helfen? |
| **ihr** | **euch** | (to/for) you guys | Ich schenke **euch** etwas. |
| **sie** (they) | **ihnen** | (to/for) them | Das Buch gehört **ihnen**. |
| **Sie** (formal) | **Ihnen** | (to/for) you | Wie geht es **Ihnen**? |

### Common phrases with dative pronouns:

| Phrase | Translation |
| :--- | :--- |
| **Wie geht es dir?** | How are you? (informal) |
| **Wie geht es Ihnen?** | How are you? (formal) |
| **Mir geht es gut.** | I'm doing well. |
| **Kann ich dir helfen?** | Can I help you? |

## Part 3: Important Dative Verbs (A1)

Some common verbs are **always followed by the dative case** – no direct object, only an indirect object [citation:9][citation:3].

| Verb | Meaning | Example |
| :--- | :--- | :--- |
| **helfen** | to help | Ich helfe **meinem Vater**. |
| **danken** | to thank | Wir danken **dir**. |
| **gefallen** | to be pleasing/to like | Das gefällt **mir**. |
| **schmecken** | to taste good | Pizza schmeckt **ihm**. |
| **gehören** | to belong to | Das Buch gehört **der Lehrerin**. |
| **gratulieren** | to congratulate | Ich gratuliere **dir** zum Geburtstag. |
| **antworten** | to answer | Antworte **mir** bitte! |
| **glauben** | to believe | Glaubst du **ihr**? |

### Examples:

| Sentence | Translation |
| :--- | :--- |
| Ich helfe **meinem Bruder**. | I help my brother. |
| Das gefällt **mir** sehr gut. | I like that a lot. (lit. That pleases me) |
| Die Schuhe gehören **meiner Schwester**. | The shoes belong to my sister. |
| **Schmeckt** es **dir**? | Do you like it? (lit. Does it taste good to you?) |
| Wir danken **Ihnen** für Ihre Hilfe. | We thank you for your help. |

## Part 4: Dative Prepositions (Always Dative)

These prepositions are **always** followed by the dative case – no exceptions [citation:5][citation:4].

| Preposition | Meaning | Example |
| :--- | :--- | :--- |
| **aus** | from/out of | Ich komme **aus der Schweiz**. |
| **bei** | at/near/with | Ich wohne **bei meiner Freundin**. |
| **mit** | with | Ich fahre **mit dem Bus**. |
| **nach** | to/after | Wir fliegen **nach Deutschland**. |
| **von** | from/of | Das ist **von meiner Mutter**. |
| **zu** | to | Ich gehe **zu meinem Arzt**. |
| **seit** | since/for (time) | Ich lerne **seit einem Jahr** Deutsch. |
| **gegenüber** | opposite | Das Hotel liegt **gegenüber dem Bahnhof**. |

### Contractions (Preposition + Article):

| Contraction | Full Form | Example |
| :--- | :--- | :--- |
| **zum** | zu + dem | Ich gehe **zum** Arzt. |
| **zur** | zu + der | Wir fahren **zur** Schule. |
| **beim** | bei + dem | Er ist **beim** Arzt. |
| **vom** | von + dem | Ich komme **vom** Zahnarzt. |
| **ausm** | aus + dem | (colloquial) Komm **ausm** Keller! |

## Part 5: Expressing "to like" – gefallen vs. mögen

A common point of confusion at A1 level:

| Verb | Case | Example | Translation |
| :--- | :--- | :--- | :--- |
| **mögen** | Accusative | Ich mag **dich**. | I like you. |
| **gefallen** | Dative | Du gefällst **mir**. | I like you. (lit. You are pleasing to me) |

### Compare:

| Sentence | Structure |
| :--- | :--- |
| **Ich mag den Film.** | Subject (Nom) + verb + object (Acc) |
| **Der Film gefällt mir.** | Subject (Nom) + verb + indirect object (Dat) |

---

## Part 6: Fixed Phrases with Dative

These common expressions use the dative case and are useful from day one [citation:1][citation:9].

| Phrase | Meaning | Breakdown |
| :--- | :--- | :--- |
| **Wie geht es dir/Ihnen?** | How are you? | How goes it **to you**? |
| **Mir ist kalt.** | I'm cold. | **To me** is cold. |
| **Mir ist schlecht.** | I feel sick. | **To me** is bad. |
| **Mir tut der Kopf weh.** | I have a headache. | **To me** hurts the head. |
| **Das ist mir egal.** | I don't care. | That is **to me** equal. |

## Summary Table: Nominative vs. Accusative vs. Dative

| | **Masculine** | **Neuter** | **Feminine** | **Plural** |
| :--- | :--- | :--- | :--- | :--- |
| **Definite Article** (the) | | | | |
| Nominative | **der** | **das** | **die** | **die** |
| Accusative | **den** | **das** | **die** | **die** |
| Dative | **dem** | **dem** | **der** | **den** (+ n) |
| **Indefinite Article** (a/an) | | | | |
| Nominative | **ein** | **ein** | **eine** | – |
| Accusative | **einen** | **ein** | **eine** | – |
| Dative | **einem** | **einem** | **einer** | – |
| **Possessive** (my/your) | | | | |
| Nominative | **mein** | **mein** | **meine** | **meine** |
| Accusative | **meinen** | **mein** | **meine** | **meine** |
| Dative | **meinem** | **meinem** | **meiner** | **meinen** (+ n) |
