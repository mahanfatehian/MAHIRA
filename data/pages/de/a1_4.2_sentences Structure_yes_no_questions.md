# Sentence Structure: Yes/No Questions (Ja/Nein-Fragen) - A1

Yes/No questions are questions that can be answered with "yes" (*ja*) or "no" (*nein*). In German, forming these questions is very simple – and different from English!

## Why this matters
- You use them constantly in daily conversations
- They follow a simple, consistent pattern
- Essential for the Goethe A1 exam (especially the speaking part)
- Much easier than in English – no "do/does" helper verb!

## The Golden Rule: Verb in Position 1!

In a Yes/No question, the conjugated verb moves to the **first position** . The subject moves to position 2, and the rest of the sentence follows.

| Statement (Verb in Position 2) | Question (Verb in Position 1) |
| :--- | :--- |
| Du **lernst** Deutsch. | **Lernst** du Deutsch? |
| Er **kommt** heute. | **Kommt** er heute? |
| Wir **gehen** ins Kino. | **Gehen** wir ins Kino? |
| Sie **hat** einen Bruder. | **Hat** sie einen Bruder? |

**Key insight:** German doesn't use helper verbs like "do" or "does" for questions. You simply swap the subject and verb!

## Part 1: Basic Yes/No Questions – The Swap

### Structure:

| Position 1 | Position 2 | Position 3 | Rest |
| :--- | :--- | :--- | :--- |
| **VERB** (conjugated) | **Subject** | (Object) | Time / Place |
| **Lernst** | du | Deutsch? | |
| **Kommst** | du | | heute? |
| **Geht** | ihr | | ins Kino? |
| **Hast** | du | einen Bruder? | |

### More examples:

| Question | Answer (Yes) | Answer (No) |
| :--- | :--- | :--- |
| **Lernst** du Deutsch? | Ja, ich lerne Deutsch. | Nein, ich lerne nicht Deutsch. |
| **Kommt** er heute? | Ja, er kommt heute. | Nein, er kommt nicht heute. |
| **Geht** ihr ins Kino? | Ja, wir gehen ins Kino. | Nein, wir gehen nicht ins Kino. |
| **Hast** du Geschwister? | Ja, ich habe einen Bruder. | Nein, ich habe keine Geschwister. |

## Part 2: Questions with "haben" and "sein"

The same rule applies to the two most important verbs:

### sein (to be)

| Statement | Question |
| :--- | :--- |
| Du **bist** müde. | **Bist** du müde? |
| Er **ist** Lehrer. | **Ist** er Lehrer? |
| Ihr **seid** aus Berlin. | **Seid** ihr aus Berlin? |
| Sie **ist** meine Schwester. | **Ist** sie meine Schwester? |

### haben (to have)

| Statement | Question |
| :--- | :--- |
| Du **hast** Hunger. | **Hast** du Hunger? |
| Er **hat** ein Auto. | **Hat** er ein Auto? |
| Ihr **habt** Zeit. | **Habt** ihr Zeit? |
| Sie **hat** eine Katze. | **Hat** sie eine Katze? |

## Part 3: Questions with Modal Verbs

With modal verbs, the **modal verb** goes to position 1. The main verb stays at the end in infinitive form .

| Statement | Question |
| :--- | :--- |
| Du **kannst** Deutsch sprechen. | **Kannst** du Deutsch sprechen? |
| Er **will** nach Berlin fahren. | **Will** er nach Berlin fahren? |
| Wir **möchten** zahlen. | **Möchten** wir zahlen? |
| Ihr **müsst** lernen. | **Müsst** ihr lernen? |

### Examples:

| Question | Answer |
| :--- | :--- |
| **Kannst** du mir helfen? | Ja, ich kann dir helfen. |
| **Will** sie einen Kaffee trinken? | Nein, sie will Tee trinken. |
| **Möchtet** ihr ins Kino gehen? | Ja, wir möchten ins Kino gehen. |

---

## Part 4: Questions with Separable Verbs

With separable verbs, the **prefix separates** and goes to the end – just like in statements. The conjugated verb (the base) goes to position 1 .

| Statement | Question |
| :--- | :--- |
| Du **stehst** früh **auf**. | **Stehst** du früh **auf**? |
| Er **ruft** seine Mutter **an**. | **Ruft** er seine Mutter **an**? |
| Wir **kaufen** im Supermarkt **ein**. | **Kaufen** wir im Supermarkt **ein**? |
| Ihr **kommt** mit. | **Kommt** ihr **mit**? |

### Examples:

| Question | Answer |
| :--- | :--- |
| **Stehst** du morgen früh **auf**? | Ja, ich stehe um 6 Uhr auf. |
| **Ruft** er heute **an**? | Nein, er ruft morgen an. |
| **Kommt** ihr ins Kino **mit**? | Ja, wir kommen gern mit. |

## Part 5: Answering Yes/No Questions

### Positive Answers (Ja)

The simplest answer is just "Ja" or "Ja, + repeat the statement".

| Question | Short Answer | Full Answer |
| :--- | :--- | :--- |
| Lernst du Deutsch? | Ja. | Ja, ich lerne Deutsch. |
| Kommt er heute? | Ja. | Ja, er kommt heute. |

### Negative Answers (Nein)

For negative answers, you use **nein** + the negative statement. Remember the difference between **nicht** and **kein**:

| Question | Short Answer | Full Answer |
| :--- | :--- | :--- |
| Lernst du Deutsch? | Nein. | Nein, ich lerne **nicht** Deutsch. |
| Hast du einen Bruder? | Nein. | Nein, ich habe **keinen** Bruder. |
| Ist das dein Buch? | Nein. | Nein, das ist **nicht** mein Buch. |
| Hast du Geschwister? | Nein. | Nein, ich habe **keine** Geschwister. |

**Rule reminder:**
- **nicht** = negates verbs, adjectives, and specific elements
- **kein- / keine** = negates nouns with "a/an" or "no" (like "not a" or "no")

---

## Part 6: Questions with Question Words vs. Yes/No Questions

It's important to know the difference:

| Question Type | Position 1 | Position 2 | Answer Type |
| :--- | :--- | :--- | :--- |
| **Yes/No Question** | **VERB** | Subject | Ja / Nein |
| | **Lernst** | du Deutsch? | Yes/No answer |
| **W-Question** | **W-Word** | Verb | Specific information |
| | **Was** | lernst | du? | "Deutsch" |

### Compare:

| Question | Expected Answer |
| :--- | :--- |
| **Lernst** du Deutsch? | Ja / Nein |
| **Was** lernst du? | Deutsch. (specific information) |
| **Kommst** du heute? | Ja / Nein |
| **Wann** kommst du? | Um 8 Uhr. (specific time) |

---

## Part 7: Intonation in Questions

In spoken German, Yes/No questions have a **rising intonation** at the end, just like in English .

| Statement (falling) | Question (rising) |
| :--- | :--- |
| Du lernst Deutsch. ↓ | Lernst du Deutsch? ↑ |
| Er kommt heute. ↓ | Kommt er heute? ↑ |

## Common Mistakes to Avoid

### Mistake 1: Using "do/does" like in English ❌
| Wrong | Correct |
| :--- | :--- |
| **Machst du** lernst Deutsch? | **Lernst** du Deutsch? |
| **Tust du** haben Hunger? | **Hast** du Hunger? |

### Mistake 2: Keeping subject before verb ❌
| Wrong | Correct |
| :--- | :--- |
| **Du lernst** Deutsch? | **Lernst du** Deutsch? |
| **Er kommt** heute? | **Kommt er** heute? |

### Mistake 3: Forgetting the separable prefix at the end ❌
| Wrong | Correct |
| :--- | :--- |
| **Aufstehst** du früh? | **Stehst** du früh **auf**? |
| **Anrufst** du mich? | **Rufst** du mich **an**? |

### Mistake 4: Confusing "nein" and "nicht" ❌
| Wrong | Correct |
| :--- | :--- |
| Nein, ich lerne **nein** Deutsch. | Nein, ich lerne **nicht** Deutsch. |
| Nein, ich habe **nicht** Bruder. | Nein, ich habe **keinen** Bruder. |
