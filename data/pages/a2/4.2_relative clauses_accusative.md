# Relative clauses: accusative - A2

If the relative pronoun is the object of the clause, masculine **der** becomes **den**. Feminine, neuter, and plural stay **die / das / die**.

## Why this matters
- *die Arbeit, die ich mache* is an object clause
- Only masculine changes in the accusative
- The verb, or the participle plus helper, still ends the clause

## The forms

| Gender | Subject | Object |
| :--- | :--- | :--- |
| masculine | der | **den** |
| feminine | die | **die** |
| neuter | das | **das** |
| plural | die | **die** |

| Sentence | Why |
| :--- | :--- |
| Das ist der Mann, **den** ich gefragt habe. | *der Mann* is the object of *fragen*. |
| Die Bewerbung, **die** ich geschickt habe, war kurz. | feminine object, no change. |
| Das Büro, **das** ich suche, soll nah sein. | neuter object, no change. |
