# Passive: the agent with von - A2

If you still want to name the person, add **von** plus the dative.

## Why this matters
- **von** answers "by whom?"
- The case after **von** is dative, so **der** becomes **dem**
- The participle still stays at the end

## The pattern

| Question | Sentence |
| :--- | :--- |
| Von wem? | Die Geschenke werden **von Anna** gepackt. |
| Von wem? | Der Brief wird **von Frau Klein** abgeschickt. |
| Von wem? | Das Paket wird **vom Nachbarn** gebracht. |

**von dem** contracts to **vom**.

| Nominative | After von |
| :--- | :--- |
| der Nachbar | **vom** Nachbarn |
| die Lehrerin | **von der** Lehrerin |
| das Kind | **vom** Kind |
| die Kollegen | **von den** Kollegen |
