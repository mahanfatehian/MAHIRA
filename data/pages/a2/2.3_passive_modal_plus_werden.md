# Passive: a modal plus werden - A2

A rule or a missing step often needs a modal. The participle stays, and **werden** moves to the end.

## Why this matters
- Forms, tickets, and signs use *muss ... werden*
- The modal takes position 2
- **werden** is an infinitive at the very end, not a conjugated verb

## The order

modal + participle + **werden**

| Sentence | Meaning |
| :--- | :--- |
| Das Formular **muss** unterschrieben **werden**. | The form has to be signed. |
| Die Adresse **soll** deutlich geschrieben **werden**. | The address should be written clearly. |
| Das Paket **kann** heute nicht abgeholt **werden**. | The parcel cannot be picked up today. |

## Question

The modal moves to position 1.

**Muss** das Formular unterschrieben **werden**?

## Mini Practice

Build the sentence.

1) Das Formular / müssen / unterschreiben
2) Die Adresse / sollen / schreiben
3) Das Paket / können / nicht abholen
4) Die Quittung / müssen / ausstellen
5) Der Brief / sollen / heute abschicken
